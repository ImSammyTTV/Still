## ✨ Features

<table>
<tr>
<td width="50%" valign="top">

### 📸 Capture anything
Drag over an area, or **hold Space** and click a window. Full screen, timers, exact sizes and aspect-ratio lock
live in the **Capture Bar** at the bottom of the screen. Open menus and Spotlight stay in the shot.

</td>
<td width="50%" valign="top">

### 🪟 A preview that waits for you
Every capture lands in a small **Floating Preview**, already copied to your clipboard. Copy, save, edit, pin or
upload it, or drag it straight into a chat, an email or a document.

</td>
</tr>
<tr>
<td valign="top">

### ✏️ Mark it up
Arrows, boxes, lines, pen, highlighter, text, numbered steps, spotlight, blur, pixelate and **solid redaction**.
Every mark stays editable, with full undo.

</td>
<td valign="top">

### 🖼️ Make it presentable
Backgrounds, padding, rounded corners, shadows and aspect ratios for posts, then **Drag to share** or save.

</td>
</tr>
<tr>
<td valign="top">

### 🔤 Copy text from anything
Select text in an image, a video or an app that won't let you copy, and Still puts it on your clipboard.
Recognition runs on your own computer.

</td>
<td valign="top">

### 🎥 Record your screen
An area or the whole screen, with microphone and computer audio. On Mac: GIF export, a camera bubble, click and
keystroke overlays, a trim bar and a video editor.

</td>
</tr>
<tr>
<td valign="top">

### 📋 Clipboard history <sub>Mac</sub>
`⇧⌘V` brings back anything you copied lately: text, images or files. Things your password manager marks as
private are skipped.

</td>
<td valign="top">

### ⬆️ Updates itself
Lives in your menu bar or tray, checks for new versions and installs them with one click. Every update is
checked against the project's signature before it installs.

</td>
</tr>

## 🚀 Quick start

1. **Download** Still for your system from the [latest release](https://github.com/ImSammyTTV/Still/releases/latest):

   | System | Download |
   |---|---|
   | <img src="assets/os-apple.svg" width="16" alt="">&nbsp;**Mac** | [one-line installer](#-macos), or `Still-…-mac-universal.zip` |
   | <img src="assets/os-windows.svg" width="16" alt="">&nbsp;**Windows** | `Still_…_x64-setup.exe` (`…_arm64-setup.exe` on ARM PCs) |
   | <img src="assets/os-linux.svg" width="16" alt="">&nbsp;**Linux** | see [Linux](#-linux) below |

2. **Open Still.** A short setup guide walks you through screen capture permission. Camera, microphone and
   sharing are optional.
3. Press **`⇧⌘4`** on Mac or **`Ctrl Shift 4`** on Windows and Linux, and drag over something.
4. Your capture is on the clipboard and waiting in the corner. Paste it anywhere, or click it to mark it up. Done!

> [!TIP]
> **Windows** may say *"Windows protected your PC"*: click **More info → Run anyway**.
> **Mac:** use the [one-line installer](#-macos) to skip macOS's security prompts entirely.

## ⌨️ Shortcuts

| Action | Mac | Windows & Linux |
|---|---|---|
| Capture an area (**hold Space** for a window) | `⇧⌘4` | `Ctrl Shift 4` |
| Open the Capture Bar | `⌃⇧⌘S` | `Ctrl Shift 5` |
| Capture a window | `⌃⇧⌘4` | `Ctrl Alt Shift 4` |
| Capture the whole screen | `⌃⇧⌘5` | `Ctrl Shift 3` |
| Copy text from the screen | set it in Settings | `Ctrl Shift 2` |
| Start or stop recording | `⌃⇧⌘6` | `Ctrl Shift 6` |
| Clipboard history | `⇧⌘V` | — |

- **While selecting:** `Shift` keeps it square, arrow keys nudge (`Shift` for 10 px, `Option`/`Alt` to resize),
  `Enter` captures, `Esc` cancels.
- **In the editor:** each tool has a letter: `A` arrow, `R` rectangle, `T` text, `N` step, `B` redact, `U` blur,
  `C` crop and so on.
- **From the right-click menu (Mac):** right-click an image in Finder, or a selected image in another app, for
  **Open in Still**, **Copy Text from Image with Still** and **Pin Image with Still**.

Change any shortcut in **Settings → Shortcuts**.

> [!IMPORTANT]
> macOS uses `⇧⌘4` for its own screenshots. If Still asks, turn off *"Save picture of selected area as a file"* in
> **System Settings → Keyboard → Keyboard Shortcuts → Screenshots**.

## 🔗 Sharing links

Run your own **Still Cloud** server (it's in [`Cloud/`](Cloud/README.md): one Python file, no dependencies), then
connect to it in **Settings → Cloud**. Press **Upload** anywhere in Still and the link is copied for you. Links can
expire, stay within your team or be private, and the viewer has comments.

Uploads also include any text Still recognised in the capture and a recording's transcript, so your server can search them.

## <img src="assets/os-apple.svg" width="26" alt=""> macOS

Open **Terminal** (press ⌘ Space, type *Terminal*, press Enter), paste this and press Enter:

```sh
curl -fsSL https://raw.githubusercontent.com/ImSammyTTV/Still/main/install-mac.sh | sh
```

It downloads the latest release, checks it against the release's checksums **and** the project's signature,
installs **Still.app** into Applications and opens it. Apple silicon and Intel, macOS 15 or later.

The first time you capture, switch Still on under **System Settings → Privacy & Security → Screen & System Audio
Recording** (the upper list). Still lives in your menu bar, not the Dock.

<details>
<summary>Installing from the zip instead</summary>

Still isn't notarized by Apple, so macOS blocks it the first time:

1. Unzip, move **Still.app** to Applications and double-click it. macOS says it can't check it: click **Done**.
2. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Still.
3. Confirm with your password. From then on it opens normally.
</details>

Uninstall: `curl -fsSL …/install-mac.sh | sh -s -- --uninstall` (your captures are kept).

## <img src="assets/os-windows.svg" width="26" alt=""> Windows

Download **`Still_…_x64-setup.exe`** from the [latest release](https://github.com/ImSammyTTV/Still/releases/latest)
and run it. On Snapdragon and other ARM PCs, use `…_arm64-setup.exe`. Prefer no installer? Run
`Still-…-windows-x64-portable.exe`.

It's about 9 MB, because Still uses the Edge WebView2 engine that's already part of Windows 10 and 11.

## <img src="assets/os-linux.svg" width="26" alt=""> Linux

Install a package from the [latest release](https://github.com/ImSammyTTV/Still/releases/latest):

| Distro | Package |
|---|---|
| Any distro | `.AppImage`: make it executable and run it |
| Ubuntu, Debian, Mint, Pop!_OS | `.deb` |
| Fedora, openSUSE, Nobara | `.rpm` |

Needs Ubuntu 24.04, Fedora 40, Debian 13 or newer. Picking a window with **Space** needs an X11 session; on Wayland,
Still captures through your desktop's screen-sharing prompt. If your desktop won't let apps set global shortcuts,
bind your own to `still --capture=area` (or `window`, `fullscreen`, `text`, `record`, `allInOne`, `history`).

## ❓ Help

<details>
<summary><b>Screen capture doesn't work on my Mac</b></summary>

Open **System Settings → Privacy & Security → Screen & System Audio Recording** and make sure Still is on in the
**upper** list (the *System Audio Recording Only* list below it doesn't allow screenshots). If it's missing, click **+**,
choose `/Applications/Still.app` and reopen Still. Still not working? **Settings → General → Open Setup Assistant →
Check Again**, and keep only one copy of Still in Applications.
</details>

<details>
<summary><b>A shortcut doesn't do anything</b></summary>

Another app may already use it. Still marks taken shortcuts in red under **Settings → Shortcuts**: click one and
press a new combination. On Mac, also check the `⇧⌘4` note under [Shortcuts](#️-shortcuts).
</details>

<details>
<summary><b>Is blur safe for hiding passwords?</b></summary>

Use **Redact** (`B`): it paints solid colour over the pixels in the saved image. Blur and pixelate are for looks and
can sometimes be reversed. Share the exported image, not the editable project.
</details>

<details>
<summary><b>How do I update?</b></summary>

Still checks for new versions and shows a small card when one is out: click **Install and Restart**. On Mac you can
also choose **Check for Updates…** in the menu bar menu; on Windows and Linux, **Settings → About**.
</details>

<details>
<summary><b>Where are my captures and settings?</b></summary>

| System | Folder |
|---|---|
| Mac | `~/Library/Application Support/Still` |
| Windows | `%AppData%\app.still.desktop` |
| Linux | `~/.local/share/app.still.desktop` (captures) and `~/.config/app.still.desktop` (settings) |

Every capture keeps its original, so you can reopen it from **Capture History** and change it later.
Updating or reinstalling never removes them.
</details>

🐛 **Found a bug or have an idea?** [Open an issue](https://github.com/ImSammyTTV/Still/issues/new). For bugs, say what
you expected, what happened instead and which system you're on. Ideas and "it'd be nice if…" suggestions are welcome too.

## 🛠️ For developers

<details>
<summary><b>Building from source</b></summary>

**Mac** (Xcode 16 or later; Swift, AppKit, SwiftUI, ScreenCaptureKit):

```sh
swift test
./scripts/build.sh        # universal Still.app next to the project folder
```

**Windows and Linux** (Node.js 20+ and Rust; Tauri app in `Desktop/`; Linux also needs the WebKitGTK and PipeWire
packages listed in [`release.yml`](.github/workflows/release.yml)):

```sh
cd Desktop
npm install
npm test                  # JavaScript and Rust tests
npm start                 # run from source
npm run build             # installers in src-tauri/target/release/bundle
```

`still --self-test=<folder>` checks capture, the preview, copying, the editor, text recognition and sharing; CI runs
it on real Windows and Linux machines. Sharing server tests: `python3 -m unittest discover -s Cloud/tests -v`.
</details>

<details>
<summary><b>Releasing (maintainers)</b></summary>

Go to **Actions → Release → Run workflow** and enter the version (e.g. `v1.3.0`). GitHub Actions builds every
download (Mac, Windows and Linux), signs the updates, writes checksums and publishes the release. It stops if any
platform is missing or the Mac app isn't signed with the project's certificate.
</details>

See [FEATURES.md](FEATURES.md) for what's built on each platform.

## 🔏 Code signing policy

<details>
<summary>How Still's downloads are signed</summary>

- **Mac** releases are signed with the project's own certificate, so macOS keeps Screen Recording permission across
  updates, and the updater and installer refuse anything signed differently. They aren't notarized by Apple, which is
  why the zip needs **Open Anyway** on first launch (the Terminal installer skips that).
- **Windows** downloads will be signed once the project's application to SignPath Foundation is approved. Until then,
  Windows may show a SmartScreen warning the first time.
- **Windows and Linux updates** are verified against the project's update signing key before they install.
- Still only contacts GitHub to check for updates, and your own Still Cloud server when you upload.
</details>
